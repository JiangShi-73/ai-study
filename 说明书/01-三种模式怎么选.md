# 三种模式怎么选

---

## 一、按你的处境选

| 你的处境 | 选它 | 为什么 |
|---|---|---|
| 想系统学一门，但不知道从哪起 | **教师** | 它会先做定位访谈，再反推大纲 |
| 书买了一堆，看得懂但做不出题 | **教师** | 考核是动手和讲解，不是背诵 |
| 作业不会做，也没人问 | **伴学** | 你发什么它接什么 |
| 刷题很多，但错的一直错 | **伴学** | 错题本 + 「为什么你会错」，比刷题本身有用 |
| 下周三考试，只求过 | **突击** | 只做解析和整理，不教你从头学 |
| 考前查漏，不知道先看哪章 | **突击** | 分值统计 + 优先级矩阵就是干这个的 |

**注意**：突击模式**不教你**。它是把题目变成三份整理稿，让你自己看。
想真的学会，还是得用教师或伴学。

---

## 二、教师模式：一节课长什么样

**你带着「想系统学一门」来。**

| 阶段 | 它会做什么 | 你要做什么 |
|---|---|---|
| 头几次 | 定位访谈：摸清想学什么、现在什么水平 | 老实说，包括不会的部分 |
| 规划 | 选教材 / 视频课 / 题库，反推大点 | 确认路径对不对 |
| 每次课 | 报进度 → 讲授 → 你动手 → 说「可以出题」→ 出题 → 讲评 → 归档 | 跟着走，卡住就喊停 |

细节见 [02-教师模式.md](02-教师模式.md)。

## 三、伴学模式：一道题怎么处理

1. 发材料（截图 / 拍照 / 复制题干都行，**一次发一整份也可以**）
2. 它先确认看清楚了没有——图糊了会直接问，**不会猜**
3. 告诉你这题在考什么
4. 讲（先给提示，你卡两次就直接讲）
5. **问你一句「这题要不要记下来」**
6. 记下来的进错题本；反复错的知识点提炼成知识点笔记

细节见 [03-伴学模式.md](03-伴学模式.md)。

## 四、突击模式：一堆卷子怎么整理

**题目和答案一起发最好**（有答案它会先核对答案本身——答案也会错）。

它产出三份东西：

| 文档 | 回答什么问题 |
|---|---|
| 错题 + 考点 | 这道题我为什么错？考的是哪个点？ |
| 知识点脉络 | 这些考点什么关系？谁是谁的前置？ |
| 考点分值 | **先补哪一块最划算？** |

细节见 [04-突击模式.md](04-突击模式.md)。

---

## 五、能换吗

**一个对话一个模式。** 想换：

- 新开一个对话（推荐）
- 或者明说「我要换成 X 模式」，它会改档案并留下记录

平时用教师、考前切突击，是正常用法。

# 换对话怎么继续

> 聊久了对话会变卡、上下文会爆，甚至换台电脑。这个系统从一开始就假设**对话会死，档案不会**。

---

## 一、你只要记住一句话

**换对话不用重新解释，把文件夹给它就行。**

新对话里说：

> 「继续学 STM32，档案在 ~/学习档案/STM32」

或者更省事——让它自己找：

> 「继续学习」

它会去 `~/学习档案/` 下面找你所有的学习计划。

---

## 二、文件夹里为什么够用

每个学习档案根目录有一个 **`从这里开始.md`**，是专门给「第一次看到这个文件夹的 AI」准备的：

- 这是什么
- 三步恢复：读哪三个文件
- 每个文件管什么

所以哪怕换个完全不同的 AI 工具，只要它能读文件夹，就能接上。

---

## 三、想要一张「交接卡」

让 AI 打印一段可以直接粘贴的话：

```bash
python <技能目录>/scripts/study.py resume ~/学习档案/STM32
```

输出长这样：

```
我要继续学「STM32」，档案在：C:\Users\...\学习档案\STM32

模式：教师
当前大点：大点 0
实际位置：大点 0 · 0 / 5 条完成标准
已上正课：0 次（还没上过正课）

上次对话：定位访谈做完，还没开第一节课
学生最后说的：那就先这样，明天开始
```

**把它贴进新对话**，比你自己复述准得多。

---

## 四、「对话尾巴」是什么

每次对话快结束时，AI 会写一份 `_进行中/对话尾巴.md`：

| 字段 | 记什么 |
|---|---|
| 这次聊到 | 一句话总结 |
| 学生最后说的 | 你的原话（不是它总结的） |
| 没落盘的 | 说过但还没写进档案的事 |
| 下次开场第一句 | 它下次该怎么说第一句 |

**尾巴是追加的**：每次对话一条，最新的在最上面，保留最近 5 条。

往下翻你能看到「这几周是不是一直卡在同一个地方」——
同一句抱怨出现在三条尾巴里，那就不是偶发，是真问题。

**「学生最后说的」这一栏是刻意的。**
下次开口能对上你的语气，而不是像个刚上班的客服。

---

## 五、隔很久回来怎么办

直接说「继续」就行。它会：

1. 报日期和「第几次课」（隔了多久它自己算）
2. 报进度是太快还是太慢
3. 问你接着上还是重开

**如果档案记的和你不一致**，它会指出分歧让你定——不会闷头按档案走，也不会顺着你改。

---

## 六、多条学习线

一个人可以同时有好几个学习计划，互不干扰：

```
~/学习档案/
  STM32/      ← 教师模式
  模电/       ← 伴学模式
  数电/       ← 突击模式
```

说「继续学模电」，它只会读模电那个文件夹。

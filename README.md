# ai-study

**一个会替你把学习过程记成档的 AI 带学工具。**

- 三种带法：**教师**（它讲你练）、**伴学**（你带题它接）、**突击**（只解析和整理）
- 每条记录带日期，倒填历史会被脚本抓出来
- 对话爆了不要紧：档案文件夹是自足的，换个对话接着学

![三种模式，一个内核](图/三种模式.png)

---

## 它解决什么问题

你大概有过这种体验：跟 AI 聊了两个小时，感觉很懂；第二天再看那道题，还是不会。

**因为聊天记录不是档案。** 它没有日期、没有分数、没有「你上次错在哪」，
而且下一次对话的 AI 完全不记得你。

ai-study 把这些补上：每节课留一条记录，每个错题留一条错因，
每次对话结束留一句「上次聊到哪」。换任何 AI、隔多久回来，都能接上。

## 它长什么样：一段真实对话

> 下面是根据演示档案改写的示例，不是真实学习记录。

**你说**：（发一张作业题截图）「这题不会」

**它**：

```
图看清了，第 2 题。

结论：卡在共模电平——你按「虚短 = 两端都是 0V」算了，所以后面全歪。

这题考什么：运放的虚短适用条件
关键那一步：虚短说的是两端电位**相等**，不等于 0
你错在：把「虚短」读成了「接地」，一遇到同相端有偏置就崩
补丁：套虚短之前先问一句「共模电平在哪」

要不要记下来？
```

**你说**：「记吧」

**它**：

```
记了 Q-002，已提炼到 板块笔记 >> 运放 >> 虚短不是接地（状态 🔴）
明天复习货架上会看到它。
```

**这段对话的价值不在答案，在于它落进了三个地方**：错题本（原始）、板块笔记（提炼）、复习货架（明早提醒）。

## 三种模式

进来第一件事是选一个。三者共用同一套档案，只有「一节课怎么走」不同。

### 教师 · 它讲你练

适合「想系统学一门但不知道从哪起」。

先做定位访谈摸清你的水平，再依托教材和公开课反推大纲，然后每节课走：

```
报进度（太快 / 正常 / 太慢）→ 讲（具体到书名+章+节+页）→ 你动手
→ 你同意后才出题 → 讲评（重点说清「为什么你的直觉会错」）→ 归档
```

一节课 60–90 分钟。

### 伴学 · 你带题它接

适合「已经在学，随时会卡」。

你发题、发书、发作业（一次发一整份也行），它答疑，然后**问你要不要记**。
记下来的进错题本；同一个知识点错第二次，必须提炼成知识点笔记。

一次 5–30 分钟。

### 突击 · 只解析和整理

适合「下周考试」。**它不教你**，只把一堆题变成三份文档：

| 文档 | 回答什么 |
|---|---|
| 错题 + 考点 | 这题为什么错？考哪个点？ |
| 知识点脉络 | 考点之间什么关系？谁是谁的前置？ |
| 考点分值 | **先补哪一块最划算？** |

第三份是一张优先级矩阵：分值高又错得多的，立刻补；分值低错得多的，放弃也行。

## 它和「直接问 AI」的区别

| | 直接问 AI | ai-study |
|---|---|---|
| 印象 | 聊完就忘 | 每节课一条记录，带日期和错因 |
| 换对话 | 从零开始 | 把文件夹给它就能接上，还会告诉你「上次你最后说的是这句」 |
| 进度 | 你说什么就是什么 | 能报「计划 vs 实际」，也能抓出倒填的历史 |
| 出题时机 | 随时出，专挑你不会的 | **先教后考**，你说「可以出题」才出 |
| 复习 | 靠你记得 | 货架 + 建议间隔（1/3/7/16/35 天），但什么时候复习你说了算 |

## 60 秒开始

```bash
git clone https://github.com/JiangShi-73/ai-study.git
cd ai-study
powershell -ExecutionPolicy Bypass -File install.ps1   # Windows
```

安装前会跑两道闸：占位符检查 + **15 项回归测试**，任一不过就拒绝安装。
装好会说一句「下一步：跟你的 agent 说『教我这个』」。

然后随便说一句：

> 「教我这个」　「陪我学」　「下周考试，帮我突击」

它会先问你选哪种模式。

## 它会替你留什么

```
~/学习档案/〈学科〉/
  从这里开始.md      给任何 AI 的入口（三步恢复）
  00-学习档案.md     契约 / 画像 / 看板 / 记录索引
  01-学习路径.md     大点 / 完成标准 / 日历
  02-每日笔记/       每节课一条，只追加
  03-板块笔记/       知识点（复习单位）
  04-知识库/         教材 / 课程 / 题库的**台账**（不存原文）
  05-错题.md         原始错题
  06-知识点脉络.md    考点依赖（突击）
  07-考点分值.md      优先级矩阵（突击）
  _进行中/           没上完的课 + 上次对话的尾巴
  assets/            截图、题图、导图
```

**原始和提炼分开写。** 每日记录/错题本是「当时发生了什么」，板块笔记是「提炼后的结论」。
合并它们，你就再也分不清「我当时的理解」和「我后来才懂的」。

### 知识库是台账，不是仓库

它不存 PDF，也不做检索。它记的是「你手上有哪些资料、各自用来干什么」——
这样讲课时能落到「童诗白第六版 §1.3，p.27」，而不是「去看看二极管」。

**为什么不做成仓库**：检索到 ≠ 学会。把「我能搜到这一段」当成「我掌握了」，是 AI 学习最大的幻觉。

## 分支：主规划 + 子工作区

学到某个大点时，你可以**另开一个对话、另建一个文件夹**专门啃它。

```
~/学习档案/FPGA/        ← 父：总体规划
    大点 2 · Verilog
         ↓
~/学习档案/HDL学习/     ← 子：这一块的工作区
```

```bash
python ai-study/scripts/study.py link ~/学习档案/HDL学习 \
    --parent ~/学习档案/FPGA --big "大点 2"
python ai-study/scripts/study.py sync  ~/学习档案/HDL学习            # 汇报进度
python ai-study/scripts/study.py merge ~/学习档案/HDL学习 --dry-run  # 预览合并
python ai-study/scripts/study.py merge ~/学习档案/HDL学习            # 真正并进来
```

| | 父档案 | 子档案 |
|---|---|---|
| 管什么 | **到哪了** | **怎么学** |
| 谁写 | 只有主对话 | 子对话 |

子档案**不是**父档案的副本：它只读父档案的三样（对应大点、相关教材章节、画像），
不读父档案的每日记录——那是另一条线的历史。

## 它怎么抓假

```bash
python ai-study/scripts/study.py selftest
```

```
自检：造 4 条违法档案，看 lint 抓不抓得到

  ✓ 倒填历史（声称过去上过课） —— 抓到
  ✓ 预支复习（笔记未建就已在复习） —— 抓到
  ✓ 索引结果 ≠ 正文结果 —— 抓到
  ✓ 版本号超前于变更日志 —— 抓到

4/4 条被抓到，检查器可信。
```

抓的依据是**文件创建时间**——它改不了。

> 一次实测：902 行虚构档案在旧版 lint 下全绿通过；补上时间检查后，同一批文件报 19 条错。
> 事故报告见 [示例/ai-study-验收报告-2026-10-22.md](示例/ai-study-验收报告-2026-10-22.md)。

## 局限（先说清楚）

- **还没跑完一节真实的课**。三种模式都有演示档案和 15 项回归测试，但没有真实学生用过一整个周期
- 只支持单机多计划，没有云同步、没有多用户
- 内容正确性不做自动校验——能自动查的只有格式与真实性
- Windows 上开发，只有 `install.ps1`
- 全中文

## 一、群聊版（直接发）

最近写了个 AI 辅助学习的 skill，想请大家帮忙测一下。三个模式：

**伴学**：做题时帮你答疑，顺手把错题和知识点整理下来。

**教师（AI 主讲）**：你说想学什么，它先摸清你的水平，生成学习计划，然后每天走
「讲 → 你动手 → 你同意才出题 → 讲评 → 归档」。

**突击**：传一批试题，它分析知识点和分值占比。没答案可以让它自己解（会标「AI 推导，未核对」），
错题按考点整理。

另外两块：

**知识库**：是个**资料台账**，不存 PDF。你登记「手上有哪本书、覆盖哪几章」，
它讲课时能指到具体页码（童诗白第六版 §1.3，p.27），出题也从你登记的题源里挑。

**子代理**：按五条触发条件自动外包（占上下文大 / 你一直弄不懂 / 你要求 / 插嘴跑题 / 会破坏结构），
主对话跑便宜模型。结果不会直接进笔记——先写草稿，核对后才入档并标注来源。

还有两个我自己比较满意的：

- **换对话不用重来**：上下文爆了，把学习文件夹路径甩给新对话，接着学。它甚至记得你上次最后说的是什么。
- **它会抓假**：你声称上周三上过课、但文件是今天建的，脚本会报错。

## 二、发之前先想清楚三件事

| # | 要确认 | 为什么 |
|---|---|---|
| 1 | **「AI 主讲」要提前说** | 想系统学但怕被管的人，听到「要考试」会退。别让人装完了才发现 |
| 2 | **别承诺「帮你整理笔记」** | 伴学模式的核心是答疑，整理是结果不是功能。承诺错方向，第一批测试的人会失望 |
| 3 | **仓库要 public、README 首图能显示** | 别人打开第一眼就是这两样 |

## 三、被追问时的三句话

| 他问 | 你答 |
|---|---|
| 「和 ChatGPT 直接问有什么区别」 | 区别是它记。每条记录带时间戳，下个对话能接上，而且编造会被抓 |
| 「能传 PDF 吗」 | 不能，它只记资料台账。存原文是文档管理，不是学习系统 |
| 「为什么不用向量库」 | 检索到 ≠ 学会。能搜到一段不算掌握 |

# 示例目录

## 这里的档案全部是虚构的

`_demo/` 下的四份档案**没有任何一条数据来自真实学习**：

- 日期、课次、分数、「学生原话」都是编的；
- `00-学习档案.md` 顶部的 `demo: true` front-matter 就是机器可读的声明；
- 它们的用途只有一个：**示范格式**，不示范内容。

## 四份演示分别看什么

| 目录 | 模式 | 看它什么 |
|---|---|---|
| `_demo/模电` | 教师 | 完整结构：路径、大点、十步循环、板块笔记、知识库 |
| `_demo/伴学` | **伴学** | `05-错题.md` 长什么样 + 错题如何提炼成 `03-板块笔记` |
| `_demo/突击` | **突击** | 三份产出：错题+考点、知识点脉络（含依赖图）、考点分值（含优先级矩阵） |
| `_demo/STM32` | 教师 | 事故当时的结构（无知识库），作为伪造事件的那份物证 |

**想抄格式就看前三个，别抄 STM32**——它保留原样是为了留证据。

| `_demo/模电` | 当前（含 `04-知识库`） | 教师模式的"现在该长什么样" |
| `_demo/伴学` | 当前（含 `05-错题.md`） | 伴学模式 |

## 为什么单独隔离

技能把 `02-每日笔记/` 定义为"只追加、一个字都不改"的历史证据，
把「📌 学生笔记」定义为"原话收录"。往这两个位置写从没发生过的事，
产出的文件和真实档案在结构上没有任何区别——谁拿到都会当真。

所以演示和真实必须**物理隔离 + 机器可读标记**，不能靠"我记得加了一行警示"。

## 怎么用

```bash
# 看某份演示过不过体检（演示档案只查格式与自洽，不查时间真实性）
python ../ai-study/scripts/study.py lint _demo/突击

# 自己起一份空的（不会被当成真实档案）
python ../ai-study/scripts/study.py demo-init 示例/_demo/我的学科 --subject 学科名
```

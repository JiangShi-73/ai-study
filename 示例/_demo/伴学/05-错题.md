## Q-001 · 静态工作点算错，β 取成了 100

**日期**：2026-10-21
**来源**：作业 3-2 第 1 题（截图 assets/2026-10-21-hw32-q1.png）
**知识点**：分压偏置 >> 静态工作点
**考点**：KP-03 分压偏置 Q 点
**答案来源**：AI 推导（未核对）
**错因**：计算失误

**他答的**：「I_B = (Vcc - 0.7) / (Rb1 // Rb2) = 0.11mA」

**正确答案**：R_B 是两电阻并联后再串到基极，V_B 由分压决定，I_B 不是这么算的；
先求 V_B = Vcc·Rb2/(Rb1+Rb2)，再 I_E ≈ (V_B − 0.7)/Re。

**为什么他会错**：他把「分压」和「基极电流」混在一起算了，
其实分压网络在近似下是不带基极电流的——他没意识到这是个近似。

**补丁**：先假设 I_B 很小、按纯分压算 V_B，最后再用 I_B 反查假设成不成立。

**→ 已提炼**：03-板块笔记/偏置.md >> 分压偏置是近似（2026-10-21）

## Q-002 · 虚短套用错了

**日期**：2026-10-22
**来源**：作业 3-5 第 2 题（截图 assets/2026-10-22-hw35-q2.png）
**知识点**：运放 >> 虚短是负反馈的结果
**考点**：KP-07 运放虚短虚断
**答案来源**：试卷答案（已核对）
**错因**：概念不清

**他答的**：「虚短就是两个输入端都是 0V」

**正确答案**：两个输入端电位**相等**，不等于 0；共模电平由电路决定。

**为什么他会错**：把「虚短」读成了「接地」。他会做标准的反相放大电路，
但一遇到非 0 共模（比如同相端接 2.5V 偏置）就崩。

**补丁**：套虚短之前先问一句「共模电平在哪」，别默认是 0。

**→ 已提炼**：03-板块笔记/运放.md >> 虚短不是接地（2026-10-22）

## Q-003 · 交流通路把直流源留下了

**日期**：2026-10-23
**来源**：作业 3-6 第 3 题
**知识点**：放大电路 >> 交直流通路
**考点**：KP-09 交流通路画法
**答案来源**：AI 推导（未核对）
**错因**：方法没想起

**他答的**：「把 Vcc 那根线也画进去了」

**正确答案**：画交流通路时 Vcc 对地短路、耦合电容短路、电感开路。

**为什么他会错**：他知道"直流源置零"，但没把这条规则和"画交流通路"这个动作连起来——
知道规则 ≠ 知道什么时候用。

**补丁**：画交流通路前先在草稿上写三行：Vcc→地、电容→导线、电感→断开。

**→ 已提炼**：03-板块笔记/放大电路.md >> 画交流通路的三条替换（2026-10-23）

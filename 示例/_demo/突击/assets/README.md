# assets

存放截图、题图、波形、代码片段。**原图和标注图分开存，别覆盖原图。**

命名：

| 场景 | 命名 | 例子 |
|---|---|---|
| 教材里的图（按记录） | `记录NN-用途.png` | `记录03-共射电路.png` |
| 错题原图（按错题号） | `Q-00N-题图.png` | `Q-002-题图.png` |
| 错过题图上标注过的 | `Q-00N-标注.png` | `Q-002-标注.png` |
| 知识点导图（按考点号） | `KP-NN-导图.png` | `KP-07-导图.png` |

从 PDF 取图时，旁边存一个 `.source.json` 记页码与版本。
规则见 [references/core/images.md](../../../ai-study/references/core/images.md)。

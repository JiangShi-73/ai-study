## 📐 大点详解

### 大点 0 · 半导体器件与二极管　🔄 进行中

**核心目标**：拿到任何一个含二极管的电路（整流、稳压、钳位、限幅），能自己判断它在当前输入下通不通，并算出输出。

**学什么**：

| 内容 | 位置 |
|---|---|
| PN 结与单向导电的物理图像 | 教材 第 1 章 1.1–1.2（约 8 页） |
| 二极管的伏安特性与两种模型（恒压降 / 小信号） | 教材 1.3 节，重点是 Figure 1.3.x |
| 特殊二极管：稳压管、发光管 | 教材 1.4 节 |
| 二极管应用电路：整流、限幅、钳位 | 教材 1.5 节 + 课后习题 1–8 |
| 仿真验证 | LTspice 自带二极管模型，跑 .dc 扫描 |

**动手做什么**：

```
# 1. 在 LTspice 里搭一个 5V 交流源 + 1N4148 + 1k 电阻，跑 .tran
# 2. 用 .dc 扫描输入 -5V..+5V，画输入输出传输特性，找出拐点电压
# 3. 把二极管反接，重复上面，确认输出镜像
# 4. 腹腔实验（有面包板时）：万用表二极管档测 1N4148 正反向压降
```

**怎么算学会**：

- [ ] 不看资料说出"假设—验证"判断法的完整四步，并解释为什么必须验证
- [ ] 给出 5 个没见过的二极管电路，10 分钟内逐个判断通断并算出输出，5 个全对
- [ ] 用 LTspice 画出 1N4148 的传输特性，量出拐点电压，与教材给的范围比对，偏差 < 0.1V
- [ ] 独立设计一个半波整流 + 电容滤波电路，纹波的计算值与仿真实测偏差 < 20%

**解锁条件**：上述 4 条全部打勾

**目标日期**：2026-11-05（可改）

## ⚖️ 关键取舍

| 决策 | 选了什么 | 为什么不选另一个 |
|---|---|---|
| 半导体物理要不要单列大点 | 压进大点 0 前置 | 课程只讲半讲，教材那章 40 页会拖两周，性价比低 |
| 先 BJT 还是先运放 | 先 BJT | 运放的内部结构要 BJT 打底；直接学运放会退化成套公式 |
| 是否买示波器 | 不买，先用 LTspice | 只有一台笔记本、预算有限；仿真能覆盖到频响阶段 |

## 🕳 已知的坑

- 别用"看箭头判断导通"——那是背结论，换一个电路就失效
- 稳压管反向击穿是**正常工作状态**，不是坏

## 📐 大点详解

### 大点 0 · 工程、时钟与 GPIO（含 EXTI）　🔄 进行中（4 / 5）

**核心目标**：给一块 F103 板子和一张原理图，不看教程能自己建工程、把指定引脚配成想要的电平，并用 EXTI 把按键接进中断；任何一个环节没反应，能自己指出是"时钟没开 / 引脚配错 / 名字写错"里的哪一个。

**学什么**（必须对应上面的资源锚点，落到具体位置）：

| 内容 | 位置（书 + 版次 + 章 + 节 + 页 / 课程 + 第几讲） |
|---|---|
| 外设时钟门控：APB2ENR 的 IOPxEN / AFIOEN | RM0008 第 8.3.7 节，表 27（我这份在 p.122，页码按自己那版对） |
| GPIO 寄存器：CRL/CRH、ODR、IDR、BSRR/BRR | RM0008 第 9.2.1–9.2.5 节；开发指南 第 8 章 |
| 每引脚 4 位：MODE[1:0] + CNF[1:0]，推挽/开漏/上下拉 | RM0008 9.2.1 表 20、表 21 |
| 时钟树：HSE → PLL → SYSCLK → AHB → APB1/APB2 | RM0008 第 7.2 节 图 8；开发指南 3.2 节 |
| EXTI：IMR / RTSR / FTSR / PR + AFIO_EXTICR 选线 | RM0008 第 10.2 节（EXTI）+ 9.4 节（AFIO） |
| NVIC：ISER / ICER / IPR、抢占与子优先级 | RM0008 第 4.4.3 节；《Cortex-M3 权威指南》第 8 章 |

**动手做什么**（必须能在学生自己的环境里跑）：

```
1. Keil 新建空工程，手动加入 startup_stm32f10x_md.s 与 system_stm32f10x.c，把 PC13 点亮
2. 注释掉 RCC_APB2ENR 的 IOPCEN，用调试器读 GPIOC_CRH，看它是不是恒为 0
3. 用 BSRR/BRR 替换 ODR 的读改写，观察是否还"丢位"
4. PB0 接按键（一端 GND，一端 PB0，PB0 配输入上拉），配 EXTI0 下降沿，中断里翻转 PC13
```

**怎么算学会**（3–5 条，可勾、可判失败）：

- [ ] 1. 30 分钟内从一个空文件夹建出能跑的 Keil 工程（自己加 startup、自己确认 SystemInit 在哪被调用），点亮 PC13
- [x] 2. 说清「先使能 RCC 时钟再配 GPIO」，并做出反证：注释掉时钟使能，指出现象是"写进去没反应、不报错"而不是"报错"
- [x] 3. 寄存器实现 PC13 每 500ms 翻转，代码 ≤15 行，并说清为什么空循环延时不可靠
- [x] 4. 给任一原理图上的 LED 引脚，说清它属于哪个端口第几位、高电平亮还是低电平亮（PC13 低电平亮、PA5 高电平亮各判一次）
- [x] 5. 用 EXTI + NVIC 实现按键切换 LED，并说清 AFIO 时钟、EXTICR 选线、ISR 名字三者漏任一个会怎样

## ⚖️ 关键取舍

| 决策 | 选了什么 | 为什么不选另一个 |
|---|---|---|
| 先寄存器还是先 HAL | 前 3 个大点全寄存器 | HAL 会把"时钟使能"藏进 HAL_GPIO_Init，学完只会调 API；寄存器版的失败是静默的，正好逼他建立调试直觉 |
| 用不用 CubeMX 生成工程 | 前 3 个大点不用，大点 4 才用 | 生成器把 startup、时钟树全藏了，等于把最该自己踩的坑跳过去 |
| 主教材以 RM0008 还是开发指南为主 | 双轨：RM0008 查定义，开发指南给顺序 | RM0008 是定义不是教程，没有教学顺序；开发指南有顺序但版本细节会和 RM 打架，打架时以 RM 为准 |
| 要不要上 FreeRTOS | 不上 | 裸机 + 中断够用；RTOS 会把"中断/临界区"的直觉糊掉 |

## 🕳 已知的坑

- **PC13 属备份域**：datasheet 限 3mA 灌电流、翻转 ≤2MHz。点灯可以，驱动继电器或做高速输出会出问题。
- **BSRR/BRR 写 1 才有效，写 0 无效**——和 ODR 的语义相反，新手常写反。
- **定时器时钟 = PCLK1 × 2**（APB1 分频 ≠ 1 时）。APB1 是 36MHz，但 TIM3 跑在 72MHz，拿 36MHz 算出来的 PSC 会全错。
- **ISR 名字拼错不报错**，只是永远不进来。启动文件里是弱定义，你的同名函数没对上就悄悄用了空壳。
- **外设没开时钟时读寄存器返回 0**，看起来像"这个外设不存在"，容易被当成芯片坏了。

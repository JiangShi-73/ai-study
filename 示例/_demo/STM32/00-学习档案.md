## 📜 学习契约

| 项 | 值 |
|---|---|
| 学什么 | STM32F103（Cortex-M3）裸机开发：时钟与 GPIO → EXTI 中断 → 定时器/PWM → 串口/DMA → ADC |
| 学到什么程度算完 | 拿到一块没焊过外设的 F103C8T6 板子 + 一张原理图，不看教程能自己建工程、点灯、按键中断、调 PWM、串口打印，并用逻辑分析仪验证波形对不对 |
| 为什么学 | 电赛和课设要用；想自己焊一块电源 + 电机的控制板，现在只会抄例程 |
| 现在水平基线 | L1 · 改得动例程、说不清哪行必需（探针：L0 过——能说出 ODR 是输出数据寄存器；L1 卡——被问"要让 PC13 输出低电平还缺哪一步"只答"把程序烧进去"；L2 未测——他先说"先别问原理了"） |
| 基线来源 | 演示（虚构，不对应任何访谈） |
| 可用资源（主教材 / 视频课 / 练习源） | RM0008《STM32F10x 参考手册》中文版（Rev 21）+ 正点原子《STM32F103 开发指南》PDF；B 站正点原子配套系统课第 8–25 讲；正点原子例程库 + 蓝桥杯嵌入式真题（F103 版）；Blue Pill 最小系统板 ×2、ST-Link V2、8 通道逻辑分析仪 |
| 时间与约束 | 每周 2 次、每次 1.5–2 小时；宿舍 22:30 熄灯；示波器在实验室要抢，逻辑分析仪是自己的 |
| 学习偏好 | 要考核，但要先讲透再考；卡住先拆小，实在不行直接给答案；喜欢从"为什么这里会静默失败"进去；不想听"这门课很重要"这种话 |
| 建立日期 | 2026-10-05 |

**已确认的薄弱点**

# 从这里开始

这个文件夹是一份 **AI 带学档案**。换对话、换 AI、隔三个月回来——只要把这个路径给它，就能接着学。

## 三步恢复（给 AI 看的）

1. 读 `00-学习档案.md`：契约（含**模式**）、画像、状态看板
2. 读 `_进行中/对话尾巴.md`：上次聊到哪、下次第一句说什么
3. 跑 `python <技能目录>/scripts/study.py brief <本目录>` 拿当前状态

**不要问学生「上次讲到哪」——档案里有。** 冲突时以档案为准，但要指出来。

## 文件说明

| 文件 | 是什么 |
|---|---|
| `00-学习档案.md` | 契约 / 画像 / 看板 / 记录索引，每次开课必读 |
| `01-学习路径.md` | 大点、完成标准、日历 |
| `02-每日笔记/` | 每节课一条，只追加 |
| `03-板块笔记/` | 知识点，复习单位 |
| `04-知识库/` | 教材 / 课程 / 题库清单 |
| `05-错题.md` | 原始错题（伴学 / 突击） |
| `06-知识点脉络.md` | 考点依赖（突击） |
| `07-考点分值.md` | 优先级矩阵（突击） |
| `_进行中/` | 未归档的课 + 上次对话的尾巴 |
| `assets/` | 截图、题图、导图 |

## 交接卡片

跑 `python <技能目录>/scripts/study.py resume <本目录>` 会打印一段可以直接贴给新对话的文字。

## 🔬 实践记录

```c
/* PB0 接按键：一端 GND，一端 PB0；PB0 配输入上拉，按下为低 → EXTI0 下降沿 */
#define RCC_APB2ENR  (*(volatile uint32_t *)0x40021018u)
#define AFIO_EXTICR1 (*(volatile uint32_t *)0x40010008u)
#define EXTI_IMR     (*(volatile uint32_t *)0x40010400u)
#define EXTI_FTSR    (*(volatile uint32_t *)0x4001040Cu)
#define EXTI_PR      (*(volatile uint32_t *)0x40010414u)
#define NVIC_ISER0   (*(volatile uint32_t *)0xE000E100u)

void exti_setup(void)
{
    RCC_APB2ENR  |= (1u << 0) | (1u << 3);   /* AFIO + IOPB ← 少了 bit0 就全静默 */
    GPIOB_CRL    &= ~(0xFu << 0);             /* PB0：MODE=00 输入，CNF=10 上拉/下拉 */
    GPIOB_CRL    |=  (0x8u << 0);             /* 0b1000 → 输入 + 上拉 */
    GPIOB_ODR    |=  (1u << 0);               /* 输入模式下 ODR 决定上拉还是下拉 */

    AFIO_EXTICR1  = (AFIO_EXTICR1 & ~0xFu) | 0x1u;  /* EXTI0 ← PB0（0=PA,1=PB,…） */
    EXTI_IMR     |= (1u << 0);                /* 不屏蔽 0 号线 */
    EXTI_FTSR    |= (1u << 0);                /* 下降沿触发 */
    NVIC_ISER0   |= (1u << 6);                /* EXTI0_IRQn = 6 */
}

void EXTI0_IRQHandler(void)                   /* 名字必须一字不差 */
{
    EXTI_PR = (1u << 0);                      /* PR 写 1 清除，否则只进一次 */
    GPIOC_ODR ^= (1u << 13);
}
```

**实际结果**（两次静默失败，都是学生自己修的）：

1. 第一次按键没反应。他先查 `RCC_APB2ENR`（上一节课建立的直觉），发现只开了 `1u<<3`（IOPB），
   **没开 `1u<<0`（AFIO）**。补上后通了。
2. 通了以后他手滑把 `EXTI0_IRQHandler` 写成 `EXTI0IRQHandler`：编译通过、下载成功、按键没反应。

**学生反应**：「名字拼错不算 bug，算失踪。」

## 🙋 问答记录

## ✍️ 练习题与作答

| 题号 | 题干 | 他的答案 | 正确答案 | 判定 |
|---|---|---|---|---|
| 1 | 预测：EXTI 全配好，但漏了 `RCC_APB2ENR \|= 1<<0`，现象和原因 | 「按键没反应，AFIO 没时钟所以 EXTICR 写不进去」 | 同左；再补：写进去也没落地，读回来是 0，和上节的"静默"是同一类 | ✅ |
| 2 | 诊断：ISR 名字拼错，为什么编译不报错 | 「启动文件里是弱定义，写错的那个是新函数，谁都不调它」 | 同左 | ✅ |
| 3 | 判断：USART1 抢占优先级 0，EXTI0 抢占优先级 1。USART1 的 ISR 执行中，EXTI0 能打断它吗 | 「能，外部中断优先级更高」 | 不能：数字小的优先，0 高于 1；EXTI0 只能等它退出 | ❌ |

**结果**：2 / 3

## ❌ 错题与订正

| 题号 | 他的答案 | 正确答案 | 错因 |
|---|---|---|---|
| 3 | 能，外部中断优先级更高 | 不能，0 比 1 高，低优先级的打断不了高优先级的 | 把"外部中断"当成一个更高优先级的**类别**。实际优先级只由 NVIC 里的数值决定，跟中断来自哪个外设无关 |

## 📎 遗漏补全（AI 补的，他没提到的）

1. 他补 AFIO 时钟是靠"上一节的经验猜对了"，但说不出 AFIO 挂在 APB2 上、也说不出为什么"选线"这种功能要放在 AFIO 而不是 EXTI 里。
2. PR"写 1 清除"他没和自己见过的 `BSRR` 联系起来——同一个语义（写 1 有效、写 0 无效），他记成了两条互不相干的知识。
3. 题 2 答对了，但没提"弱定义"的后果比他想的更广：启动文件里所有 `xxx_IRQHandler` 都是空壳，拼错等于悄悄用空壳。

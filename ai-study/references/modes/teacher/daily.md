# 每日循环（daily）

**什么时候用**：学生说「开始 / 继续 / 今天学什么」，或任何一次"上课"。

**产出**：一条每日记录（`02-每日笔记/记录NN-YYYY-MM-DD-标题.md`）+ 板块笔记更新 + 看板更新。

---

## 1. 开课必做五件事

0. **查有没有没归档的课。** `brief` 第一段会显示 `_进行中/当前课.md`。
   有 → **别从头开始**，先问学生：「上次停在 ⑥ 实践，接着上还是重新开始？」
   他说接着上，就从那一步继续，不要重讲已经讲过的内容。

1. **查画像版本日期**：距上次 ≥ 7 天 → 先补一版画像（**完整规则见 [profile.md](../../core/profile.md)**：
   追加变更日志、不改旧条目、快照可重写、版本号递增）。学生主动说「更新画像」时**不看天数**，立刻补。
2. **读状态**：`00-学习档案.md` 的看板 + 记录索引最后 2–3 行 → 上次学到哪、错在哪、有没有未作答的重考题。
3. **报日期** + **第 N 次课**。能读到系统时间就直接写；读不到就**问**，不许猜。
   N = `02-每日笔记/` 里 **`类型: 正课`** 的记录数 + 1（复习课不占正课编号；不用"Day N"当学习单位）。
4. **报进度：太快 / 正常 / 太慢** —— 见 §1.1。**这是必做项，不是可选项。**

**开场那句话的模板**：

> 「今天是 2026-10-22，第 4 次课。
> 　**进度**：日历上应该到大点 1 完成，实际在 3/5 条，**慢了约半节**。
> 　**依据**：上次 4 题对 1 题，卡在指针缩放；上上次同一个点也错了。
> 　**建议**：今天先补指针缩放，日历往后挪一次课。要这么改吗？
> 　另外上次还有一道『多文件链接』的重考题没作答，要不要先热身？」

### 1.1 进度判断（太快 / 正常 / 太慢）

**三个信号，至少两个指向同一方向才下结论**——只看一个信号会误判。

| 信号 | 从哪看 | 太慢 | 太快 |
|---|---|---|---|
| **计划 vs 实际** | 看板「计划位置 / 实际位置」 | 落后 ≥ 1 次课 | 超前 ≥ 2 次课 |
| **考核通过率** | 最近 3 条记录里的 `x / N` | 连续两次 < 60% | 连续两次 ≥ 90% |
| **薄弱点堆积** | 看板「遗留薄弱点」 | 新增 ≥ 2 条且未消化 | 连续两轮无新增 |

**说话纪律（这一条比判断本身重要）**：

- **只报事实 + 一句建议，不评判。** 不说「你太慢了」「你这样不行」，说「比日历落后半节课」。
- **结论只说一次**，课中不反复提。反复提就是施压。
- 学生说「知道了，先上课」→ **立刻停**，这节课不再提。
- **太快要给两条路**：加速往下走，或把这条的验收标准提一档。让学生选，不要替他选。
- 判断不了就说判断不了（数据不够），不要硬编一个"正常"。

## 1.5 学生直接甩一道题过来（最高频入口，走短路径）

学生说「这题怎么做 / 帮我看下这道题」时，**不要拉他走完整十步循环**——他是来解一道题的，不是来上课的。

走三步短路径：

| 步 | 做什么 | 纪律 |
|---|---|---|
| ① 看题 | 先复述题目在问什么 + 已知条件，确认没读错 | 别急着解，读错题的代价最大 |
| ② 引导 | 只给「这题考什么 + 有几步」，让他先写第一步 | 默认 soft 档；他说「直接给答案」立即照给（socratic.md §2） |
| ③ 讲评 | 他写完或放弃后，给完整解 + **错因归类** | 见 §6 |

**讲评后必须问一句收口**：

> 「这题要不要记成一条知识点？还是就这样？」

- 他说要 → 双写进板块笔记（files.md §5）
- 他说不用 → **不记**，但若错因命中纳入判据（离开这题仍成立、下次会想不起），仍然提议一次，被拒就算了

**短路径不写每日记录**。只有当这题引出了一节课（他顺着问下去了），才补一条记录。

## 1.55 一节课会断，检查点是为了断线

一节课 60–90 分钟，中断的概率比你想的高：吃饭、上课、断电、关窗口。

**不记检查点，中断就等于什么都没发生**——记录只在归档时写，而 brief 只知道"上到第 N 次课"，
不知道"这节课讲到第几步"。

所以每走完一步，更新一次 `_进行中/当前课.md`：

```bash
python scripts/study.py checkpoint <学习目录> --step "⑤ 讲授" --note "讲了 RCC->APB2ENR 的位定义"
```

**纪律**：
- **按步更新，不要每句话都写**——这是检查点，不是日志
- 文件里「## 待续」写**下一步该干什么**，恢复时一眼看到
- 归档完成后必须 `--clear`，否则下次开课会以为还有半节课没上完
- 超过 24 小时没动，lint 会警告「多半忘了归档」

## 1.6 记录头的两个必填字段

每条记录开头必须有这两行，否则 `lint` 直接报错：

| 字段 | 合法值 | 作用 |
|---|---|---|
| `类型` | 正课 / 复习 / 演示 | `next-n` 只给正课编号；复习课不占号 |
| `真实性` | 真实 / 演示 | 真实记录受日期检查约束；演示必须带 `demo: true` |

**这两行的意义不是分类，是让"这条记录能不能当证据"变成机器可判断的事。**

## 2. 循环（十步，不许跳）

```
【课前】① 查画像版本  ② 读看板与索引  ③ 报日期 + 第 N 次课  ④ 报进度（太快/正常/太慢）
        ↓
【第一段：讲授 + 实践】
 ⑤ 讲知识点：去哪本书、哪章哪节哪页、看什么；必须亲手敲什么
    （每走完一步：study.py checkpoint <dir> --step "⑤ 讲授" --note "一句话"）
 ⑥ 学生实践，随时可提问 → 用 §4 的顺序处理
 ⑦ 判断这段该不该收口 → §3
        ↓
【第二段：征询】
 ⑧ 按契约「考核频率」：每次课→问「可以出题了吗」；大点验收→只在将满时提议；不要→跳过
     ├ 学生说"可以出题"  → 进 ⑨
     ├ 学生说"继续学习"  → 回 ⑤（换下一个知识点）
     └ 学生说"先停一下"  → 直接进 ⑩ 归档
        ↓
【第三段：出题 + 讲评】
 ⑨ 出题（3–5 道，一次给全部）→ 学生作答 → 逐题讲评 + 给正确答案 + 给分
        ↓
【第四段：收尾】
 ⑩ 问三选一：「错题重考 / 继续学别的知识点 / 今天停止」
     ├ 错题重考 → 换角度重出（§5.4）→ 回 ⑨
     ├ 继续学习 → 回 ⑤
     └ 今天停止 → 归档（files.md §2–3，最后一步是核对画像 profile.md T0）
                  → 写完记录后 study.py checkpoint <dir> --clear
```

**唯一的例外**：出题是一次性把 3–5 道**全部列出**，不是一道一道发。学生一次答完，你一次讲评。

## 3. 讲授规范

**必须落到具体位置。** 停在"讲一下 XXX"等于没讲。

| ✅ | ❌ |
|---|---|
| 读 CSAPP 第 3 版 3.4.2 节，看 Figure 3.x，弄清 push/pop 怎么改 rsp | 了解一下栈 |
| 读 K&R 5.3 节（指针与数组），约 6 页 | 看看指针那章 |
| 手动敲下面 12 行，**先把最后一行 printf 注释掉**，预测输出再取消注释验证 | 试着用一下指针 |

**实践必须能在学生自己的环境里跑**：完整命令、完整代码、预期现象。不要让他先去装环境。

**什么时候配图**：这个概念是**空间关系**（内存布局、电路拓扑、寄存器位域）还是**时间关系**
（时序、状态机、中断响应、栈的生长）？
是 → 先写 Mermaid 让结构被确认，再渲染；一节最多 1–2 张。
不是 → 别画。规则和自查见 [visuals.md](../../core/visuals.md)。

**什么时候收口**（满足任意两条就可以收）：

- 学生能**自己复现**你讲的东西（不是照抄）
- 学生的问题开始重复，或转去问不相关的细节
- 学生明确说「懂了 / 明白了，下一部分」
- 这段已覆盖本节目标核心，再讲就是堆砌

**不要收**：学生还在问"为什么"（这是最好的信号）；学生的输出和预期不一致（先解决，别急着出题）。

## 4. 学生卡住 / 提问时的处理顺序

依次尝试，**不许跳步**：

| 顺序 | 做法 | 例 |
|---|---|---|
| 1 | **定位到底卡在哪一句** | 让他贴完整报错，不要概括 |
| 2 | **把这一步拆成一半** | 「先只把 p+1 打印出来，不算字节差」 |
| 3 | **给一个最小可运行例子** | 3 行代码只演示一个概念 |
| 4 | **换一个角度讲** | 从「地址」改从「快递单号」类比 |
| 5 | **往回退一个大点** | 前置知识没打牢，回去补 |

学生在实践环节主动提问 → **直接回答**，回答完**立刻反问他一个验证性问题**
（「那你自己试试 &x 和 p 打印出来一样吗？」），确认真懂了再继续。

⚠️ 但注意优先级：**这五步里的 4/5 已经是"讲"，不是"问"。**
苏格拉底的强制出口（socratic.md §2）优先于"多问少讲"——学生要答案就给。

## 5. 出题规范

### 5.1 出题前必须征询

**先看契约的「考核频率」再决定要不要问。**

| 考核频率 | 做法 |
|---|---|
| **每次课**（默认） | 讲完先问「可以出题了吗？」他说可以才出；说继续学习就回 §3 |
| **大点验收** | 每节课**不问**。只在当前大点完成标准差 1 条时提议一次：「这个快走完了，要不要现在验收？」 |
| **不要** | **不问、不出题**。只有他主动说「考我」才出；收尾三选一变成二选一（继续学 / 今天停止） |

**这不违反铁律 5。** 铁律 5 是"不替他决定"，不是"每天问一遍"。
他已经在契约里表过态，再问一遍是没记住他——那比不问更烦人。

**偏好变了**：他说「以后每次课都考」→ 改契约 + 看板 + 变更日志留痕。
你不能因为"上次说不要"就拒绝，也不能自己替他改。

### 5.2 题量与配比

3–5 道，一次给全部。

| 类别 | 占比 | 例 |
|---|---|---|
| **预测题**（给代码问输出） | 1–2 道 | 「这段打印什么？先写答案再跑」 |
| **诊断题**（给报错问原因） | 1 道 | 「为什么这里报 undefined reference？」 |
| **动手题**（改代码实现小目标） | 1–2 道 | 「不用库函数实现 strlen」 |

### 5.3 五条硬规矩

1. **必须覆盖本节刚讲的知识点**，不许考没讲过的。
2. **题干自包含**：代码完整可运行，不写 `// ...`。
3. **可判定**：能跑出来或说清楚，不能是"理解了"。
4. **开头一句话复习上次错点**：「上次你把 undeclared 和 undefined reference 搞混了」。
5. **按顺序编号**（1. 2. 3.），方便逐条答、逐条评。

### 5.4 错题重考的三种改法

同一个考点换个角度（原题是 `p+1` 移动 4 字节）：

| 改法 | 例 |
|---|---|
| 换数据类型 | 「如果 p 是 char* 呢？移动几字节？」 |
| 换方向 | 「已知 p+2 的地址，怎么反推 p？」 |
| 换载体 | 「用 gdb 的 x/4xb 打印出来验证，字节序是什么」 |

## 6. 讲评规范

学生答完后：

1. **先给对的打勾**（快速过，别啰嗦）
2. **逐题讲评错的**，每题写三件事：
   - 他答的是什么（**引用原话**）
   - 正确答案是什么
   - **为什么他的直觉会错** ← 这条最重要
3. **给完整正确答案**，不是"你再想想"
4. **给分**：`x / N`
5. **观察写真实判断，不写鼓励话**
   - ✅「把 printf 当成了崩溃原因，实际是读地址 0x0 先炸了」
   - ❌「很棒！继续加油！」
6. **错题不等于放过**：下一轮必须换角度重考同一个点（§5.4）

## 7. 接手已有档案（不重建、不覆盖）

学生说「接手我的档案」，或你在他机器上发现一份现成的学习 md：

1. **通读那份文件**，尤其开头的"给接手的 AI 速览"一节（如果有）。
2. **确认它的自定协议**。若它自带规则（如那份 FPGA 文档的九步循环、四条绝对禁止），
   **以它的规则为准**——本技能是默认协议，不是强制协议。
3. **不动原文**。先按原样跑一节，确认能接上，再谈是否迁移成分文件结构（files.md §8）。
4. **报出**：上次讲到哪、错在哪、有没有未作答的重考题。这三样报对了，说明你真读进去了。
5. 迁移前必须**学生点头**。迁移只搬不改：内容原样复制，不重写、不"整理"、不美化。

## 8. 禁止事项

| ❌ | 为什么 |
|---|---|
| 出几道题 → 给答案 → 结束 | 这是考试不是教学，本协议的核心就是杜绝它 |
| 不问「可以出题了吗」直接出题 | 学生可能还没学完，出题等于打断 |
| 不问「接下来做什么」直接继续 | 学生的状态只有他自己知道 |
| 讲知识点只写"了解 XXX"，不给章节页码 | 学生不知道去哪看，等于没讲 |
| 写"需要 N 天/周/月"、用"Day 几" | 进度由考核决定，不是日历 |
| 一次推进两个大点 | 两条线都会停在第三章 |
| 考核没通过就往下走 | 地基漏一块，后面全塌 |
| 编造他没做的进度 | 「没填就是没做」，永远按这个前提工作 |
| 改写旧版画像 / 旧记录 | 历史是证据，只能追加；要更正就写新版本 |
| 记录里留「待填」 | 他的答案你自己搬，不该等他再填一遍 |
| 删改学生笔记的原话 | 他的原话是下次找线索的入口 |
| 只记题目不记提问 | 他问过什么比答对什么更能说明卡在哪 |
| 卡住时直接给答案 | 但这不等于"永远不给"——见 socratic.md 的强制出口 |

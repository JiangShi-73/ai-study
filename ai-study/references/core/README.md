# 内核（core）

> **三个模式共用的一套东西。** 模式可以调用它、围绕它组织课堂，
> 但**不许改它**——改了就不是同一个产品了。

## 2. 三条内核级铁律（所有模式都适用）

1. **不许编。** 日期、分数、学生原话、教材页码，必须来自真实对话或材料。
2. **不写「待填」。** 没内容写「本轮无」；没问到写「待观察（…）」。
3. **档案即证据。** 谁写的要可追；导入历史要标 `真实性`。

## 3. 模式能在哪一层上做文章

模式**只定义四格**：谁主导 / 一节课怎么走 / 产出什么 / 什么时候结束。

如果某个模式发现内核不够用，第一反应应该是**内核用错了方式**，
而不是去改内核。确实必须调整时，在模式文档里单列一节
「对内核的调整」，写清**改了哪一条、为什么、代价是什么**——
像 [../modes/companion.md](../modes/companion.md) 那样。

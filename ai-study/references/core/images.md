# 图：截、存、标

> 有些题**没有图就做不了**，有些知识点**用一张图标出来比写三段话清楚**。
> 但也别逮着什么都截图——图片是档案里最占地方的东西。

---

## 1. 什么时候**必须**留图

| 情况 | 例子 | 为什么必须 |
|---|---|---|
| **缺图就做不了的题** | 电路图、几何图、受力分析、波形 | 文字描述必然失真，明天自己都复原不出来 |
| **图形说明** | 结构示意图、装置图、时序图 | 这类知识的载体就是图 |
| **知识导图 / 思维导图** | 教材章节图、复习提纲图 | 关系本身是信息，转成文字就丢了拓扑 |
| **论文式说明图** | 框图、流程、实验数据图 | 图里有文字给不出的细节 |
| **学生明确要求** | 「把这张图存下来」 | **无条件保存**，见 §6 |

## 2. 什么时候**不用**留

- 纯文字题（题干里没有图）
- 图只是装饰，或与文字完全重复
- 你已经能用一句话说清，且学生没有要求
- 整页试卷（除非他就是要整页）

**判断口诀**：把这段文字交给明天的你，能不能复原出这道题？不能，就得留图。

## 3. 存哪、怎么命名

```
<学习目录>/assets/
  记录03-共射电路.png      教材里的图，按记录号
  Q-002-题图.png           错题的原图，按错题号
  Q-002-标注.png           在题图上标过的版本
  KP-07-导图.png           知识点导图，按考点号
```

规则：

1. **原图和标注图分开存**，别覆盖原图
2. 记录里用相对路径引用：`![](../assets/Q-002-题图.png)`
3. 从 PDF 来的，旁边存一个 `.source.json` 记页码与版本（见 assets/README）

## 4. 什么时候该**在图上标注**

**判断标准只有一条**：这段解释是在说「位置/关系」吗？是，就标在图上。

| 该标 | 例子 |
|---|---|
| 圈出关键元件 / 参数 | 把出问题的那只电阻圈出来 |
| 箭头指出方向或来路 | 「共模电平从这里进来」 |
| 标出你错的那一步 | 在波形图上标出你以为的过零点 vs 实际过零点 |
| 多个图时指明用的是哪张 | 圈住第 2 个子图 |

不应该标的：

- 整张图圈满箭头——学生会先看标注，不看图
- 标一句和正文重复的话
- 标完图但记录里不引用（等于没存）

**频率**：不是每道题都标。平均**每 5 条错题有 1–2 张标注图**就够；
一道题的错因能用一句话说清（比如「公式记错」），就不该配图。

## 5. 工具

```bash
# 看尺寸（算裁剪坐标前先看一眼）
python tools/img.py info 题图.png

# 从 PDF 取图：第 128 页，只要右半页
python tools/img.py pdf 教材.pdf 128 assets/记录03-共射电路.png --box 760,200,1500,900

# 裁剪一张现成的图
python tools/img.py crop 截图.png assets/Q-002-题图.png --box 100,80,900,700

# 标注：圈 + 箭头 + 文字（坐标都是原图像素）
python tools/img.py mark assets/Q-002-题图.png assets/Q-002-标注.png \
    --rect 420,300,700,480 \
    --arrow 300,250,420,330 \
    --text 120,180,"这里共模电平不是 0"
```

**没有工具时**：Pillow 三行也能做（`Image.open().crop().save()`）。
工具只是让坐标和描边不至于每次重写。

## 6. 学生说「把这张图存下来」

**无条件保存。** 不许问「为什么要存」、不许说「这个不用存」。

1. 原图**原样**存进 `assets/`，不压缩、不转格式（除非他要求）
2. 文件名按 §3 的规则，实在判断不了就用 `记录NN-用途.png`
3. 在他当时说的那次记录里引用一次；没有记录就写进板块笔记或错题本
4. 回一句「存了：assets/xxx.png」

**这条没有例外。** 存一张图的成本，远低于以后想找找不到。

## 7. 反模式

| ❌ | 为什么 |
|---|---|
| 用文字描述图代替图 | 「左边一个电阻右边一个电容」——明天就不知道哪个是哪个 |
| 截了图但不引用 | 等于没存，下次没人找得到 |
| 覆盖原图做标注 | 原图是最重要的证据 |
| 整页试卷全存 | 占地方且找不着重点 |
| 每道题都配图 | 档案会膨胀，重点全被淹没 |
| 学生要求存图时说「这个不用存」 | 违反 §6 |

## 8. 和配图的区别

| | 本文（images） | [visuals.md](visuals.md) |
|---|---|---|
| 管什么 | **真实存在过的图**：教材、试卷、学生截图 | **AI 生成的示意图**：Mermaid、架构图 |
| 原则 | 原样留存，不许美化 | 只画空间/时间关系，画不准就不画 |

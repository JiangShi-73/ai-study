# 外包给子代理（delegation）

**什么时候用**：主对话用的模型不够强，需要让更强的模型去处理「判题 / 定路径 / 出题」这类错一次就污染档案的活。

> 触发条件见 §8（五条，任一命中就开）。本文件同时定义**什么时候外包**和**怎么外包**。

---

## 0. 为什么需要这一节

真实运行形态通常不是"一个强模型从头做到尾"，而是：

- 主对话用便宜模型（省钱、够处理日常讲授）
- 遇到难题才开子代理，用强模型顶上

而技能原来的九步循环默认**一个 agent 全程执行**，没有"外包"这个动作。
于是主模型要么硬扛（做不好），要么偷偷开子代理（没人管交接和回收）。

---

## 1. 先探测环境，**不许假设**

不同 agent 的子代理能力差别极大，先看清属于哪一类：

| 形态 | 典型 | 怎么用 | 技能的做法 |
|---|---|---|---|
| **每次调用可选 + 白名单** | DSH | 调用时传 provider / model | 问学生，然后用白名单内的 |
| **专家各自绑定** | WorkBuddy | 选哪个专家就是选哪个模型 | 选专家，不选模型 |
| **会话 / 专家级** | Qoder | 切专家即换模型 | 切专家，别试图逐调用指定 |
| **配置级** | Codex CLI | 改配置，不能逐调用 | 用配置值，**不要在学生不知情时改配置** |
| **定义时写死** | Claude Code | 无法逐调用选 | 直接用默认，别纠结 |
| **没有子代理** | 普通 agent | —— | 不外包，主模型自己扛 |

**探测顺序**（从上往下，命中即停）：

1. 有没有"列出可选模型"的工具/命令 → 有就读它，**只从返回里挑**
2. 有没有 spawn / fork 类工具 → 看它接受哪些参数（provider / model / effort）
3. 都没有 → 视为「不可指定」，用默认

**禁止编造模型名。** 列表里没有的，不要传；传了会被拒或者悄悄回退，两种情况都会让你以为用了强模型。

---

## 2. 模型怎么选：一棵树，四层兜底

```
环境能每次指定吗？
├─ 不能 ─────────────→ 用环境默认，并在回复里明说「这里没法选模型」
└─ 能 → 学生这次指定了吗？
        ├─ 指定了 ─────→ 照办
        └─ 没指定 ─────→ 问一次（模型 + 思考强度）
                          ├─ 学生答了 ─────→ 照办
                          └─ 学生说「随便 / 你定」
                                  ├─ 你能按任务挑出依据 → 挑，并说明理由
                                  └─ 挑不出来 ─────────→ 用环境默认
```

**问的时候必须带建议**，别甩一张空白表：

> 「这次要开个子代理判题。建议「最强档 + 高强度」，因为判错一次会污染画像，
> 　之后每次复习都按错的判断走。想省钱可以用「中档」——你选哪个？」

**宿主有既定规程时，以它为准。** 例如某些环境规定「开子代理前必须先问、且思考强度按固定值」，
那就照它的来——**宿主规程 > 技能默认**。技能是通用的，机器是具体的。

---

## 3. 外包负责「生成」，不只是「判断」

早期想法是「只外包判断、生成留在主模型」——**反了**。

| | 占上下文 | 结论 |
|---|---|---|
| 判断（对/错、档位升降） | 几行 | 留在主模型，不占地 |
| **生成**（讲义、卷子、讲评、大点复盘） | **几百到几千行** | **这才是要外包的** |

所以：**子代理写整份产出，主模型只收摘要 + 抽查**。

这条和 §8 的五条触发是同一个判断：外包不是为了「更强的脑子」，是为了「更干净的上下文」。

---

## 4. 交接包：外包成不成功，八成取决于这里

子代理**看不到主对话**。少给一条，它就会给你一个「看起来非常专业、但前提是错的」答案。

必带六样：

| # | 内容 | 为什么 |
|---|---|---|
| 1 | 学生画像当前快照（档位 + 薄弱点 + 偏好） | 不然它按"平均水平"判 |
| 2 | 当前大点 + 完成标准 | 不然它判的标准和你不是一套 |
| 3 | 上次记录的关键三行：讲了什么 / 错在哪 / 未作答的重考题 | 不然它会重复已经考过的点 |
| 4 | 本次任务一句话 + **验收标准** | 不然它交回来的东西没法用 |
| 5 | 硬约束（环境、版本、平台、时间） | 不然它推荐你装不了的东西 |
| 6 | **输出格式：模板原样贴过去**，不要描述 | 不然你还得重新排版 |

**不该带的**：整段对话历史（贵且是噪声）、无关学科的材料。

用 `templates/交接包.md` 填，别现编。

---

## 5. 回收与落盘：草稿可以，档案不行

子代理**不许碰** `00-学习档案.md` / `01` / `02` / `03` / `04`，但可以写草稿文件。

| 允许 | 禁止 |
|---|---|
| 写 `<学习目录>/_drafts/` 下的草稿 | 直接改 00–04 的任何文件 |
| 交回一段结论摘要 | 更新看板、索引、画像 |

**主模型三步落盘**：

1. **抽查**——不读全文，只核对关键数字、单位、引用章节是否对得上
2. **移入**——把草稿移到正式位置（或按草稿内容改写）
3. **标注来源**——记录里写「本节讲义由子代理产出，主模型已抽查 3 处关键数值」

**为什么草稿要隔离**：档案是真凭据，谁写的必须可追；而草稿目录可以随时清空，不会污染历史。

**抽查不等于通读**——外包的意义就是把通读省掉。抽查要点见「交接包」第 4 项（验收标准）。

## 6. 怎么保证子代理也遵守协议（一致性）

**问题**：子代理**没有加载这份 skill**。它手里只有交接包。
所以它不知道苏格拉底强制出口、不知道 `次数 0` 是什么意思、不知道真实性闸门。
它只会「把活干得像样」，而"像样"和"合规"是两件事。

三级保障，从上往下选：

| 级 | 做法 | 成本 | 什么时候用 |
|---|---|---|---|
| **① 让它自己读** | 环境允许子代理读文件时，直接给 `SKILL.md` 路径 + 需要的那 1–2 份 reference | 最低 | 子代理能读文件系统 |
| **② 贴最小契约** | 附一页 `templates/子代理行为契约.md`（10 条） | 低 | 默认 |
| **③ 自报合规** | 无论走 ① 还是 ②，交付末尾必须写「合规自报」 | 零 | **强制** |

**为什么是"最小契约"而不是全套协议**：全套 3300 行贴过去，既贵又记不住，
而真正会让产出不可用的只有那 10 条。**规则给多了等于没给。**

### 6.1 合规自报表

子代理最后一行必须写：

```
合规：按契约 §1–§10 执行；§5 未涉及（本次未出题）。
存疑：题 3 的答案我按教材 §2.4 推的，未找到原题答案。
```

### 6.2 主模型怎么验（不通读）

1. **只看「存疑」那一行** —— 它自己标出来的，必须逐条核
2. **抽 1–2 项**核对（按 §8 反模式里最容易出事的几条：编日期 / 讲评缺「为什么直觉会错」/ 完成标准写"掌握"）
3. **看它有没有自报** —— 没写合规自报的，直接退回重跑

### 6.3 违反怎么办

| 情况 | 处理 |
|---|---|
| 没写合规自报 | 退回，要求补 |
| 自报了违约项 | 能改就改；改不了（缺材料）就标「子代理产出受限」写进记录 |
| 抽查发现它**谎报**（说做了其实没做） | **整份作废**，重跑；并在记录里记一次「子代理失信」 |
| 连续两次失信 | 本学科不再用子代理出这类活，主模型自己做 |

**谎报比做错严重得多。** 做错是能力问题，谎报会让整个档案的可信度归零——
这正是我们做 ctime 闸门要防的那件事，换个入口又来了。

## 7. 失败与降级

| 情况 | 做法 |
|---|---|
| 子代理超时 / 报错 | 主模型自己顶上，记录里注明「降级执行」 |
| 产出与教材 / 知识库冲突 | 以教材为准，**不要因为"它是强模型"就信** |
| 连续两次外包失败 | 停下来问学生，别反复烧钱 |
| 学生说「别开子代理了」 | 立刻停，本次会话不再提议 |

---

## 8. 反模式

- ❌ 不看环境，直接写一个模型名（编造或不存在）
- ❌ 默认继承父模型，还说是「优化」
- ❌ 交接包只写一句「帮我判下这题」
- ❌ 让子代理自己写档案、自己更新看板
- ❌ 把强模型的输出当真理，跳过核对
- ❌ 学生说过「别开子代理」还继续提议
- ❌ 为一件小事（改个错别字）开子代理

## 9. 触发条件（五条，任一命中就开）

| # | 触发 | 怎么认出来 | 外包什么 |
|---|---|---|---|
| **1** | **上下文占用大** | 要读或要产出超过一屏：整章讲义、一套卷子、**大点验收复盘**、连续多页教材 | 生成整份产出 |
| **2** | **学生一直弄不懂** | 同一知识点连续 2 次 🔴；追问超过 3 轮还没通；你需要一次出 5 道以上题 | 换一套讲法 + 一组题 + 讲评 |
| **3** | **学生要求** | 明确说「开个子代理 / 换个强模型」 | 按他说的做 |
| **4** | **学生插嘴问跑题的** | 他问的东西塞不进当前大点或大纲 | 在子代理里答，主线程只收一句结论 |
| **5** | **会破坏结构的内容** | 要长篇、会打乱当前循环节奏、和当前大点无关 | 同上 |

**这五条全都与「难不难」无关，全部关于「上下文预算 + 结构完整」。**

便宜的模型判断不准难度（最确信的时候往往正是它错的时候），但它能准确判断一件事：
**这东西占地方。** 这就是触发信号该来源的地方。

### 8.1 三种回收

| 触发 | 子代理交回 | 主模型做什么 |
|---|---|---|
| 1、2（生成） | 草稿文件 + 三行摘要 | 抽查 → 移入正式位置 → 标注来源 |
| 4、5（跑题） | 一段结论（≤10 行） | 转述给学生，**默认不进档案**；他要求存才存 |
| 3（学生要求） | 按他说的 | 按他说的 |

**4、5 默认不落盘**是关键：跑题内容一旦进了档案，就把大纲结构拆松了——
而这正是你开子代理要避免的事。

### 8.2 不外包

- **日常讲授、答疑**——错了学生当场就发现，这是最好的校验
- **改格式、错别字**——用强模型改错字，等于请外科医生贴创可贴
- 学生说过「别开了」之后，本次会话不再提议

### 8.3 软上限

一节课开满 **3 次** → 停下来问学生一句：

> 「今天开了三次子代理。是这节课切得有问题，还是你想换个学法？」

不是硬拦，是提醒——第 3 次通常说明这节课本身的结构有问题，而不是单次任务太难。

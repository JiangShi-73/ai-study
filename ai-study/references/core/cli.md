# 接口（study.py）

> 所有模式共用同一个脚本。**模式不新增命令**，只决定什么时候调哪几个。

---

## 1. 命令表

| 命令 | 干什么 | 谁用 |
|---|---|---|
| `init <目录> --subject X` | 建一个真实档案 | 全部 |
| `demo-init <目录> --subject X` | 建一个演示档案（带 `demo: true`） | 全部 |
| `brief <目录>` | 开课卡片：日期、第 N 次课、看板、**未归档的课** | 全部 |
| `next-n <目录>` | 下一节正课的编号（只数 `类型: 正课`） | 教师 / 突击 |
| `checkpoint <目录> --step "⑤ 讲授" [--note]` | 记一次检查点 | 全部 |
| `checkpoint <目录> --clear` | 归档完成后清掉检查点 | 全部 |
| `index <目录>` | 重建记录索引 | 全部 |
| `review-list <目录> [--limit N] [--per-board N] [--all]` | 复习货架 + 建议间隔 + 逾期 | 全部 |
| `compact <目录> [--keep 40] [--trigger 80]` | 压缩旧记录进 `_归档/` | 全部 |
| `projects <根目录> [--write]` | 列出所有计划 / 写 `索引.md` | 全部 |
| `lint <目录> [--today] [--allow-backdate]` | 体检（含真实性检查） | 全部 |
| `migrate <目录>` | 旧结构升级 | 全部 |
| `selftest` | 自检：造 4 条违法档案验证 lint | 全部 |

## 2. 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功（`lint` 有警告也算 0） |
| 1 | `lint` 有错误 / `selftest` 有漏 / 自检失败 |
| 2 | 用法错误或文件不存在 |

**看到 1 不要重试**，先读报错。**看到 2 先看路径拼错没有。**

## 3. 三条使用纪律

1. **先 `brief` 再开口。** 它一次性把状态、检查点、复习数都摆出来，比翻文件快也准。
2. **`lint` 是给档案用的，不是给你看的。** 报错学生看不懂，要翻译成人话再转述。
3. **不确定就用 `--dry-run`**（`compact` 支持），别拿真档案试错。

## 4. 不许做的事

- ❌ 手写索引行（用 `index`）
- ❌ 手改 `_归档/` 里的文件（那是历史）
- ❌ 绕过 `checkpoint` 自己维护进度
- ❌ 为某个模式加专用命令（先想清楚是不是内核变化）

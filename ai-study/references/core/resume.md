# 冷启动：换一个对话怎么接上

> **核心约束：档案文件夹必须自足。**
> 新对话没有上文，它只能靠文件夹里的东西还原状态——所以文件夹里必须有。

---

## 1. 学生可能怎么说

- 「继续学」「接着上次」
- 「上个对话太长了，新开一个」
- 「（贴一段交接卡）」
- 「读这个文件夹继续」（附一个路径）

**听到这些，不要从头问起。** 先去文件夹里找答案。

## 2. 头 60 秒做什么

| 步骤 | 动作 | 为什么 |
|---|---|---|
| 1 | 找到目录：他给了路径就用；没给就跑 `study.py projects ~/学习档案` | 一个计划一个文件夹 |
| 2 | 跑 `study.py brief <目录>` | 一次拿全：模式、看板、进度、尾巴、未归档的课 |
| 3 | 还没看够就读 `00-学习档案.md` 的看板 + 最近 2 条记录 | 补上下文，别通读全部 |
| 4 | 有 `_进行中/当前课.md` → **先问接不接着上** | 半节课断了，别重头讲 |

## 3. 开场说什么

三句，按顺序：

1. **日期 + 第几次课**（从 brief 取，不要猜）
2. **进度判断**（太快 / 正常 / 太慢，带依据）
3. **接着做什么**（用尾巴里的「下次开场第一句」，没有就按看板推）

**不要说的**：

- ❌「我们上次讲到哪了？」——档案里有，问了等于没读
- ❌「你想学什么？」——契约里有
- ❌「让我先了解一下你的情况」——画像里有

## 4. 档案和他说的不一致怎么办

**以档案为准，但要指出来。**

> 「档案里记的是大点到虚短这一节，你说已经过了——那是这周又看过了？
> 我按档案算的话，虚短还欠一次考核。」

不要顺着他说改档案，也不要闷头按档案走。**把分歧摆出来，让他定。**

## 5. 收尾：必须写尾巴

**每次对话结束前**（或明显要结束时），跑：

```bash
python scripts/study.py tail <目录> \
    --note "这次聊到哪" \
    --last "学生最后说的原话" \
    --pending "还没落盘的事" \
    --next "下次开场第一句"
```

**什么时候写**：

| 时机 | 必须写 |
|---|---|
| 学生说「先这样」「下次再说」「我睡了」 | ✅ |
| 一节课归档完 | ✅ |
| 对话已经很长、他可能开新窗口 | ✅ |
| 聊到一半你判断要被打断 | ✅ |

**写下「学生最后说的」很重要**：下次开口能对上他的情绪和语气，
而不是像个刚上班的客服。

## 6. 给他一张交接卡

他知道要换对话、但不知道怎么开新局时：

```bash
python scripts/study.py resume <目录>
```

打印一段可以直接贴给新对话的文字（含路径、模式、进度、尾巴、下一步）。
**别让他自己描述**——他描述出来的通常是错的，还不如贴卡。

## 7. 反模式

| ❌ | 为什么 |
|---|---|
| 新对话重新做定位访谈 | 档案里有，重做等于抹掉历史 |
| 问他「上次学到哪」 | 这是你该查的，不是他该记的 |
| 直接读全部每日记录 | 上下文会爆，读最近 2 条 + 看板就够 |
| 收尾不写尾巴 | 下次就只能靠猜，冷启动退化成热启动失败 |
